# 角色数据契约

状态：frozen（2026-08-10，T00）

## `CharacterDefinition` 字段

| 字段 | 类型 | 必填 | 校验 | 用途 |
|---|---|---:|---|---|
| `id` | `StringName` | 是 | 非空、目录内唯一、稳定不随文案变化 | 会话保存与测试标识 |
| `display_name` | `String` | 是 | 去空格后非空 | 选择卡片和单人 HUD/结算称呼 |
| `portrait` | `Texture2D` | 是 | 非空 | 选择卡片展示 |
| `head_texture` | `Texture2D` | 是 | 非空 | 装配到 `Boat/Head.texture` |
| `sort_order` | `int` | 是 | 大于等于 0；同值再按 id | 列表稳定排序 |

MVP 不允许角色 Resource 携带抓钩速度、得分倍率、技能或解锁状态。

## 角色目录

- 运行时使用一个显式 `Array[CharacterDefinition]` 目录资源或场景导出字段，不依赖运行时扫描文件夹。
- 首批包含 `boy`、`girl`，ID 唯一。
- UI 只遍历目录、生成卡片并发出所选 ID；不写 `if boy/if girl` 分支。
- 非法定义在测试中失败；运行时不得进入 READY。

## 扩展验收

测试中加入第三个合法角色定义后，排序后的选择数据包含三项，且无需修改选择 UI 脚本。该测试证明数据扩展边界，不要求提供第三套正式美术。

# 会话状态与信号契约

状态：frozen（2026-08-10，T00）

## 状态

| 状态 | 含义 | 允许意图 |
|---|---|---|
| `MODE_SELECT` | 尚未选择模式 | 选单人、选多人 |
| `CHARACTER_SELECT` | 单人等待选角色 | 确认角色、返回模式 |
| `READY` | 会话已配置、回合待开始 | 开始、返回模式 |
| `PLAYING` | 回合进行中 | 活动玩家发射 |
| `RESULT` | 回合已结算 | 再来一局、返回模式 |

`RoundController` 继续只管理 `READY/PLAYING/WON/LOST/DRAW`；应用级选择状态不得硬塞进回合枚举。应用编排层根据会话是否配置决定是否允许 `RoundController` 进入 READY/PLAYING。

## 会话字段

| 字段 | 类型 | 必填 | 合法值/默认 | 说明 |
|---|---|---:|---|---|
| `mode` | enum | 是（配置后） | `SINGLE`, `LOCAL_MULTI`; 初始未设置 | 当前游戏模式 |
| `selected_character_ids` | `Dictionary[int, StringName]` | 是 | 单人 `{1: id}`；多人 `{1: boy, 2: girl}` | 槽位到角色 |
| `active_player_ids` | `Array[int]` | 是 | 单人 `[1]`；多人 `[1,2]` | 唯一参与者真源 |
| `is_configured` | bool/派生值 | 是 | 初始 `false` | 只有合法选择完成后为真 |

## 意图与结果

| 意图 | 前置状态 | 成功后 | 失败行为 |
|---|---|---|---|
| `select_single()` | MODE_SELECT | CHARACTER_SELECT | 保持原状态 |
| `select_local_multi()` | MODE_SELECT | READY | 保持原状态 |
| `confirm_single_character(id)` | CHARACTER_SELECT 且 id 有效 | READY | 保持原状态并不装配 |
| `start_round()` | READY 且 configured | PLAYING | 返回 false，无副作用 |
| `restart_round()` | RESULT | READY，保留会话 | 非 RESULT 忽略 |
| `return_to_mode_select()` | CHARACTER_SELECT/READY/RESULT | MODE_SELECT，清空选择 | PLAYING 中默认拒绝 |

## 不变量

1. 只有 `active_player_ids` 中的玩家可启用抓钩、计分、显示个人 HUD 或领取个人效果。
2. 单人模式不得产生 P2 分数变化、P2 发射或 P2 获胜。
3. 多人仍按当前先达目标或超时比分判定胜负/平局。
4. 返回菜单前先清空效果、复位鱼钩与波次，不能把上一局状态带入新会话。

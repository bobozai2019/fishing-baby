## UI/场景边界

| 对象 | MVP 行为 |
|---|---|
| `GameSetupOverlay` | 启动可见；模式页与角色页互斥；阻挡下层玩法输入 |
| 单人角色卡 | 显示头像和名称，可键盘焦点、鼠标点击、触控点击 |
| `GameHud` | 单人只显示所选名称/P1 分数和 P1 个人效果；多人保持 P1/P2 |
| `RoundResultOverlay` | 单人显示角色结果和单一分数；多人保持双人结果；提供重开与返回模式 |
| `Boat2/HookRigP2` | 单人隐藏且禁用；多人恢复可见可用 |

## 输入门禁

1. MODE_SELECT/CHARACTER_SELECT：玩法区点击、Q、P、空格不得发射或开始旧回合。
2. READY：沿用空格/Enter/开始按钮开始回合。
3. 单人 PLAYING：Q、空格、合法水域点击/触控控制 P1；P 和右键不得触发 P2。
4. 多人 PLAYING：保留 Q/P 和左右水域分区规则。
5. 同一物理帧的选择/开始输入不得穿透并触发鱼钩。

## E2E 场景

| ID | 流程 | 核心断言 |
|---|---|---|
| E01 | 启动→单人→男孩→开始→发射 | 仅男孩与一套钩/HUD，P2 输入无效 |
| E02 | 启动→单人→女孩→开始→结算→重开 | 女孩装配到主船，重开仍为女孩 |
| E03 | 单人结算→返回模式→多人→开始 | 选择已清空，多人双船双钩恢复 |
| E04 | 启动→多人→双人输入→结算 | 当前胜负/平局规则不退化 |
| E05 | 各选择页键盘/鼠标/触控 | 焦点可见，输入不穿透 |

# 决策记录

## ADR-001：多人含义

- 日期：2026-08-10
- 状态：accepted
- 决策：MVP 的多人沿用本地双人同屏；在线多人明确排除。
- 影响：不新增网络层、房间、账号或同步协议。

## ADR-002：单人逻辑槽位

- 日期：2026-08-10
- 状态：accepted
- 决策：单人始终使用逻辑玩家 P1，角色身份与玩家槽位分离；所选角色装配到主船，P2 禁用。
- 影响：最大限度复用现有计分、抓钩和效果代码，避免两套单人分支。

## ADR-003：角色扩展方式

- 日期：2026-08-10
- 状态：accepted
- 决策：角色使用 `CharacterDefinition` Resource 和显式角色目录；UI 从目录生成卡片。
- 影响：新增角色以新增 `.tres` 和美术资源为主，不修改选择 UI 分支。

## ADR-004：导航语义

- 日期：2026-08-10
- 状态：accepted
- 决策：“再来一局”保留模式和角色；“返回模式选择”清除会话选择。
- 影响：结算层新增一个意图信号，重置玩法状态后才返回菜单。

## 实施内容

1. 由同一 `_physics_process` 分支实现契约中的四种轨迹。
2. 所有轨迹使用累计 delta，不使用墙钟时间，保证暂停后连续恢复。
3. FISH/CREATURE 加入 `aquatic_life` group。
4. 实现 `set_wave_active()` 与 `set_movement_paused()`，明确 AVAILABLE/HOOKED/COLLECTED 行为。
5. 重置恢复位置、方向、相位、暂停标志、碰撞和纹理。

## 验收标准

- 河豚、海马、乌贼和海龟均满足契约路径，不越出各自边界。
- 水母旧 DRIFT 行为无明显回归。
- 冰冻期间 AVAILABLE 水生物位置不变但仍可挂钩；HOOKED 目标继续跟钩。
- 重开后相位与初始位置完全恢复。

# Fishing Baby 三波水生物与即时道具扩展决策记录

## ADR-001：使用三波固定时间刷新

- 日期：2026-08-08
- 状态：accepted
- 背景：用户明确选择真正的分批刷新，而非只向固定关卡增加节点。
- 决策：现有与新增目标统一分配到三波，在已用时间 0、30、60 秒激活；未捕获目标保留，不在换波时移除。
- 影响：关卡内容场景、波次控制器、重开逻辑和测试。

## ADR-002：首批内容为 4 生物与 3 道具

- 日期：2026-08-08
- 状态：accepted
- 决策：新增河豚、海马、乌贼、海龟，以及涡轮卷线器、金色巨钩、蓝色冰晶。
- 影响：Resource、美术、场景布局与资源清单。

## ADR-003：道具即时生效且不中断出钩

- 日期：2026-08-08
- 状态：accepted
- 决策：道具触碰后立即消耗，当前钩子保持 `EXTENDING`；速度与大钩只作用于拾取者，冰冻作用于全场水生物。
- 影响：钩子碰撞分支、效果控制器、HUD 和双人集成测试。

## ADR-004：效果采用平衡 5 秒档

- 日期：2026-08-08
- 状态：accepted
- 决策：出收钩速度 ×1.75，大钩尺寸 ×1.6，全场水生物停止移动；三者均持续 5 秒。同类效果只重置持续时间，不叠加强度。
- 影响：效果计时、钩子计算、重置和测试断言。

## ADR-005：重算提前获胜目标

- 日期：2026-08-08
- 状态：accepted
- 背景：新增生物后总可得分从 2640 增至 3920。
- 决策：局时保持 90 秒，提前获胜目标改为 1800，保持约 46% 的可获得总分占比；超时仍按双方实际得分判胜或平局。
- 影响：LevelDefinition、HUD、结算、平衡测试和设计文档。

## ADR-006：使用正式 ImageGen 素材

- 日期：2026-08-08
- 状态：accepted
- 决策：按现有美漫平涂规范生成 9 个最终透明 PNG；内置 ImageGen 使用平坦色键背景，本地去背并验证 Alpha。未经用户另行确认，不改用 CLI 原生透明方案。
- 影响：T01、美术验收、资源清单与 Web 导入。

## ADR-007：外部系统保持范围外

- 日期：2026-08-08
- 状态：accepted
- 决策：不新增 HTTP API、数据库、持久化、随机掉落或 Windows 导出预设。
- 影响：`契约/API契约.md`、T05 验收范围。

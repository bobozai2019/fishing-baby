# 状态机与信号契约

状态：frozen（Gate 1，2026-08-08）

## 1. 总体数据流

```text
RoundController.time_changed
  -> Main 计算已用时间
  -> WaveController.update_elapsed()
  -> 激活到期波次并发出 wave_started

HookController Tip 碰到 PowerupPickup
  -> PowerupPickup.consume()
  -> HookController.powerup_collected
  -> Main 转交 PowerupEffectController.activate()
  -> Hook/Catchable 状态变化 + HUD 倒计时
```

## 2. WaveController

根节点：现有 `DemoCatchables`，下设 `Wave1`、`Wave2`、`Wave3`。

公开接口：

```gdscript
signal wave_started(wave_index: int)

func reset_waves() -> void
func update_elapsed(elapsed_seconds: float) -> void
func get_active_wave_count() -> int
```

约束：

- `reset_waves()` 递归重置 Catchable/Powerup，激活 Wave 1，禁用 Wave 2/3。
- `update_elapsed()` 使用 `>=` 阈值并循环补激活所有到期波次，重复调用幂等。
- 新波只追加，不隐藏旧波，也不重置旧波实体。
- 波次激活必须同时设置可见性、处理状态和碰撞状态。

## 3. Catchable 扩展

新增公开接口：

```gdscript
func set_wave_active(active: bool) -> void
func set_movement_paused(paused: bool) -> void
```

约束：

- `set_wave_active(false)` 隐藏并关闭 monitoring、monitorable 和碰撞，不改变 definition 或实例 ID。
- `set_wave_active(true)` 只恢复 `AVAILABLE` 实例；已收集实例不得因波次更新复活。
- `set_movement_paused(true)` 只暂停 AVAILABLE 状态的自主移动，仍保持可碰撞和可捕获。
- HOOKED 状态无视移动暂停，继续跟随载体。
- FISH 与 CREATURE 在 `_ready()` 加入 `aquatic_life` group；PICKUP/TRASH 不加入。

## 4. PowerupPickup

状态：

```gdscript
enum PowerupState { AVAILABLE, CONSUMED }
```

公开接口：

```gdscript
func consume() -> bool
func reset_powerup() -> void
func set_wave_active(active: bool) -> void
```

约束：

- 仅 AVAILABLE 且波次已激活时 `consume()` 返回 `true`。
- 成功消费后立即隐藏并关闭碰撞；后续调用返回 `false`。
- 不附着到钩子、不开始收回、不发出计分事件。
- 重开时恢复 AVAILABLE，但仍受所在波次是否激活控制。

## 5. HookController 扩展

新增 Signal：

```gdscript
signal powerup_collected(player_id: int, definition: PowerupDefinition)
```

新增接口：

```gdscript
func set_speed_multiplier(multiplier: float) -> void
func set_size_multiplier(multiplier: float) -> void
func clear_modifiers() -> void
```

碰撞分支：

1. 仅在 `EXTENDING` 处理 Catchable 或 PowerupPickup。
2. Catchable 保持原有挂钩与 `RETRACTING_CATCH` 流程。
3. PowerupPickup 成功消费后发出 Signal，状态仍为 `EXTENDING`。
4. 两个钩子同帧进入同一道具时，以 `consume()` 首次成功者为准。

速度规则：

- SWINGING 不乘速度倍率。
- EXTENDING：`extend_speed * speed_multiplier`。
- RETRACTING_EMPTY：`base_retract_speed * speed_multiplier`。
- RETRACTING_CATCH：`base_retract_speed * speed_multiplier / weight_multiplier`。

尺寸规则：

- `HookSprite.scale`、`CollisionShape2D.scale`、精灵热点偏移和碰撞中心偏移乘以尺寸倍率。
- `Tip.position` 与 Rope 终点保持不变，确保绳端仍接在钩环。
- 倍率恢复为 1.0 时不得积累浮点缩放误差，始终由基础常量重新计算。

## 6. PowerupEffectController

公开接口：

```gdscript
signal effect_time_changed(effect_kind: PowerupDefinition.EffectKind, player_id: int, seconds_left: int)

func configure(hooks_by_player: Dictionary) -> void
func activate(definition: PowerupDefinition, player_id: int) -> bool
func clear_all() -> void
```

计时键：

- 个人速度：`(HOOK_SPEED, player_id)`。
- 个人尺寸：`(HOOK_SIZE, player_id)`。
- 全局冰冻：`(FREEZE_AQUATIC, 0)`，其中 `player_id = 0` 表示全局。

约束：

- 相同键再次激活时，剩余时间直接重置为 definition 的 5 秒，不叠加倍率。
- 不同键可以同时倒计时。
- HUD 秒数使用 `ceili(remaining)`；仅在显示秒数变化、激活或清除时发 Signal。
- 冰冻激活/到期通过 `aquatic_life` group 调用 `set_movement_paused(true/false)`。
- `clear_all()` 恢复两个钩子的基础倍率、解除冰冻、清空计时并向 HUD 发送 0。
- 回合结束和重开均调用 `clear_all()`。

## 7. Main 编排

Main 负责：

- 连接 `time_changed` 到波次推进。
- 连接两个钩子的 `powerup_collected` 到效果控制器。
- 将 `wave_started` 转为“第 N 波出现！”反馈。
- 将效果倒计时转发给 HUD。
- 开始回合前确保 Wave 1 已就绪。
- 回合结束清除效果；重开按“波次 → 道具效果 → 钩子 → UI → RoundController”顺序重置。

Main 不负责：

- 每帧实现移动轨迹。
- 每帧持有临时效果时钟。
- 硬编码某个具体道具的纹理或倍率。

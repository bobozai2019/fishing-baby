## 2. HUD 状态行

- 位于现有 TopBar 下方，跨屏宽布局。
- 左侧显示 P1 的加速/巨钩，中央显示全局冰冻，右侧显示 P2 的加速/巨钩。
- 每个可见徽标包含小图标、短名称和向上取整秒数，例如 `加速 5`。
- 剩余时间为 0 时隐藏对应徽标，不保留空白占位。
- 状态行不得阻挡开始面板、结果面板或水域点击区域，`mouse_filter = IGNORE`。
- 颜色沿用深蓝底、金色边框、高对比浅色文字；冰冻使用蓝色辅助色。

## 3. 波次视觉反馈

- Wave 2/3 激活时复用 FeedbackLabel 显示“第 2 波出现！”/“第 3 波出现！”。
- 新实体允许 0.20–0.30 秒的淡入加缩放动画，但碰撞与逻辑在波次激活时立即有效。
- 不添加会遮挡目标的全屏波次横幅。

## 4. 正式美术规范

- 风格：现有 `american-cartoon-flat-no-lighting`，粗深色轮廓、平涂、小色板。
- 尺寸：最终 PNG 统一 1024×1024，主体完整、居中且保留安全边距。
- 背景：内置 ImageGen 先生成纯色 chroma-key，按主体颜色选择 `#00ff00` 或 `#ff00ff`。
- 禁止：文字、水印、投影、地面、反射、渐变、场景元素和背景纹理。
- 去背：使用安装的 ImageGen `remove_chroma_key.py`，启用 soft matte 与 despill。
- 验收：有 Alpha 通道，四角全透明，无明显绿/品红色边，主体无裁切。
- 河豚、海马分别提供游动与被捕获姿态；乌贼、海龟复用单姿态并使用现有挂钩挣扎旋转。

## 6. E2E 场景

### E2E-01 三波刷新

1. 进入 READY，仅 Wave 1 可见。
2. 开始回合，60 秒剩余时 Wave 2 出现。
3. 30 秒剩余时 Wave 3 出现。
4. 前两波未捕获目标仍存在，反馈文字各出现一次。

### E2E-02 个人加速

1. P1 触碰涡轮卷线器。
2. 钩子继续伸出，P1 显示 `加速 5`。
3. P1 出/收钩明显加速，P2 速度不变。
4. 5 秒后 P1 恢复基础速度，徽标消失。

### E2E-03 个人大钩

1. P2 触碰金色巨钩。
2. P2 钩子精灵与碰撞范围增大，绳端仍接在钩环；P1 不变。
3. 5 秒后恢复且无热点漂移。

### E2E-04 全局冰冻

1. 任一玩家触碰蓝色冰晶。
2. 所有 AVAILABLE FISH/CREATURE 停止移动，但仍能被任一钩捕获。
3. 垃圾、宝物和道具不受影响。
4. 5 秒后水生物从当前位置继续原轨迹。

### E2E-05 争抢、胜负与重开

1. 两个钩子同时接近同一道具，仅一方获得效果。
2. 任一玩家达到 1800 分立即获胜；未达到时 90 秒结束按高分判胜，等分为平局。
3. 重开恢复 90 秒、双方 0 分、Wave 1 和全部未消费初始状态；Wave 2/3 再次隐藏。

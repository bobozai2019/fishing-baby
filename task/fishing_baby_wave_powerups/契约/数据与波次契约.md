状态：frozen（Gate 1，2026-08-08）

## 1. LevelDefinition 扩展

| 字段 | 类型 | 必需 | 默认/目标值 | 校验 | 说明 |
|---|---|---:|---|---|---|
| `target_score` | `int` | 是 | `1800` | `> 0` | 达到后立即结束并判该玩家获胜 |
| `wave_start_elapsed_seconds` | `PackedFloat32Array` | 是 | `[0.0, 30.0, 60.0]` | 首项为 0、严格递增、末项 `< duration_seconds` | 已用时间阈值，不是剩余时间 |

`duration_seconds` 保持 90。其余钩子与回合参数保持现值。

## 2. CatchableDefinition 扩展

枚举必须只在末尾追加，保持现有 `.tres` 的整数序号兼容：

```gdscript
enum MovementKind {
    STATIC = 0,
    HORIZONTAL = 1,
    DRIFT = 2,
    VERTICAL = 3,
    ZIGZAG = 4,
    ELLIPSE = 5,
}
```

新增字段：

| 字段 | 类型 | 必需 | 默认值 | 校验 | 使用者 |
|---|---|---:|---|---|---|
| `movement_amplitude` | `Vector2` | 是 | `Vector2(0, 20)` | 分量 `>= 0` | DRIFT、ZIGZAG、ELLIPSE |
| `movement_frequency_hz` | `float` | 是 | `0.25` | `>= 0` | DRIFT、ZIGZAG |

实例字段新增：

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `movement_min_y` | `float` | `410.0` | VERTICAL 的上边界 |
| `movement_max_y` | `float` | `1010.0` | VERTICAL 的下边界 |

现有水母使用 `DRIFT` 默认振幅和频率，运行效果需保持与改动前接近。

## 3. 新生物定义

| ID | 名称 | 分类 | 轨迹 | 速度 | 轨迹参数 | 分值 | 重量 | 视觉初值 | 碰撞半径 |
|---|---|---|---|---:|---|---:|---:|---:|---:|
| `pufferfish` | 河豚 | FISH | DRIFT | 70 | 幅度 `(0,28)`，`0.30 Hz`，X 220–850 | 180 | 1.15 | 0.14 | 45 |
| `seahorse` | 海马 | FISH | VERTICAL | 45 | Y 500–780 | 240 | 1.00 | 0.12 | 38 |
| `squid` | 乌贼 | CREATURE | ZIGZAG | 150 | 幅度 `(0,65)`，`0.55 Hz`，X 1100–1760 | 360 | 1.25 | 0.15 | 48 |
| `sea-turtle` | 海龟 | CREATURE | ELLIPSE | 55 | 半径 `(170,60)` | 500 | 2.10 | 0.18 | 62 |

轨迹规则：

- DRIFT：X 水平折返，Y 为 `sin(TAU * time * frequency_hz) * amplitude.y`。
- VERTICAL：X 不变，Y 在实例边界间折返。
- ZIGZAG：X 水平折返，Y 使用 `[-1,1]` 三角波乘以 `amplitude.y`。
- ELLIPSE：以初始位置为中心，`amplitude` 为半径；按 `movement_speed / max(radius)` 推进相位，使速度量级仍以 px/s 表达。

## 4. PowerupDefinition

枚举：

```gdscript
enum EffectKind {
    HOOK_SPEED = 0,
    HOOK_SIZE = 1,
    FREEZE_AQUATIC = 2,
}
```

字段：

| 字段 | 类型 | 必需 | 校验/默认 |
|---|---|---:|---|
| `id` | `StringName` | 是 | 非空、全局唯一 |
| `display_name` | `String` | 是 | 非空 |
| `effect_kind` | `EffectKind` | 是 | 枚举值合法 |
| `duration_seconds` | `float` | 是 | `5.0`，必须 `> 0` |
| `magnitude` | `float` | 是 | 速度 `1.75`、尺寸 `1.60`、冰冻 `1.0` |
| `texture` | `Texture2D` | 是 | 非空 |
| `visual_scale` | `float` | 是 | `> 0`，按最终素材微调 |
| `collision_radius` | `float` | 是 | `> 0`，初值 36 |

定义表：

| ID | 显示名 | EffectKind | 时长 | 倍率/值 |
|---|---|---|---:|---:|
| `speed-reel` | 涡轮卷线器 | HOOK_SPEED | 5.0 | 1.75 |
| `giant-hook` | 金色巨钩 | HOOK_SIZE | 5.0 | 1.60 |
| `freeze-crystal` | 蓝色冰晶 | FREEZE_AQUATIC | 5.0 | 1.00 |

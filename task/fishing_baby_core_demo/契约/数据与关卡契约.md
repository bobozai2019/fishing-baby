# 数据与关卡契约

状态：`frozen`

## 1. `CatchableDefinition` Resource

| 字段 | 类型 | 必需 | 默认 | 校验 | 用途 |
|---|---|---:|---|---|---|
| `id` | `StringName` | 是 | - | 非空、全局唯一 | 稳定类型 ID |
| `display_name` | `String` | 是 | - | 非空 | UI/调试显示 |
| `category` | `CatchableCategory` | 是 | - | `FISH/CREATURE/PICKUP/TRASH` | 逻辑分类 |
| `score_value` | `int` | 是 | `0` | `>= 0` | 送达后加分 |
| `weight_multiplier` | `float` | 是 | `1.0` | `0.5..3.0` | 回收速度除数 |
| `movement_kind` | `MovementKind` | 是 | `STATIC` | `STATIC/HORIZONTAL/DRIFT` | 运动模式 |
| `movement_speed` | `float` | 是 | `0.0` | `>= 0` | px/s |
| `swim_texture` | `Texture2D` | 是 | - | 资源可加载 | 默认视觉 |
| `caught_texture` | `Texture2D` | 否 | `null` | 鱼类必填 | 被抓时视觉 |
| `visual_scale` | `float` | 是 | `1.0` | `> 0` | 场景显示缩放 |
| `collision_radius` | `float` | 是 | - | `> 0` | 手工调整的简化碰撞 |

重量影响：`effective_retract_speed = base_retract_speed / weight_multiplier`。

## 4. 关卡摆放契约

- `demo_catchables.tscn` 必须实例化至少 12 个 `Catchable`，上表每个 ID 至少一个。
- 每个场景实例必须具有唯一 `instance_id: StringName`；`definition.id` 是类型 ID，不得替代实例 ID 用于去重结算。
- 固定摆放在 `.tscn` 中完成，不在 `_ready()` 循环生成。
- 任意目标初始不重叠，不与船或水面相交，且至少有 3 个低价值物与 3 个高价值物位于不同角度。
- 游动目标只在水下可玩边界内移动，越界前折返。

## 5. 无持久化契约

- 不读写 `user://`、浏览器 localStorage、注册表、数据库或远程 API。
- 运行时分数、已捕获 ID 和倒计时仅位于当前场景内存。
- 结束进程后再启动必须是全新局。

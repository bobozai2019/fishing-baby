# 状态机与信号契约

状态：`frozen`

## 1. 抓钩状态机

```text
DISABLED --(回合开始)--> SWINGING --(有效输入)--> EXTENDING
EXTENDING --(命中目标)--> RETRACTING_CATCH
EXTENDING --(命中边界/最大长度)--> RETRACTING_EMPTY
RETRACTING_CATCH --(回到原点)--> SWINGING
RETRACTING_EMPTY --(回到原点)--> SWINGING
SWINGING --(回合结束)--> DISABLED
```

| 当前状态 | 允许输入 | 碰撞监测 | 携带物 | 主要行为 |
|---|---:|---:|---:|---|
| `DISABLED` | 否 | 否 | 否 | 停在原点 |
| `SWINGING` | 是 | 否 | 否 | 在 -65°..65° 往复摆动 |
| `EXTENDING` | 否 | 是 | 否 | 按当前角度增加绳长 |
| `RETRACTING_EMPTY` | 否 | 否 | 否 | 按基础速度减少绳长 |
| `RETRACTING_CATCH` | 否 | 否 | 是，且只有 1 个 | 按重量降速回收 |

不变量：
- 同一时刻只有一个抓钩状态。
- 每次 `EXTENDING` 最多接受一个目标，首次成功 attach 后立即关闭碰撞。
- 一次出钩只发射一次 `shot_completed`。
- 得分只在 `RETRACTING_CATCH` 回到原点后产生。

## 2. 抓取物状态机

```text
AVAILABLE --(attach_to_hook 成功)--> HOOKED --(collect)--> COLLECTED
COLLECTED --(关卡重置)--> AVAILABLE
HOOKED --(关卡强制重置)--> AVAILABLE
```

| 状态 | 移动 | 可碰撞 | 可见 | 允许结算 |
|---|---:|---:|---:|---:|
| `AVAILABLE` | 按定义 | 是 | 是 | 否 |
| `HOOKED` | 跟随抓钩 | 否 | 是 | 到达原点时 |
| `COLLECTED` | 否 | 否 | 否 | 否 |

## 3. 回合状态机

```text
BOOT --(场景/数据验证通过)--> READY
READY --(点击/空格)--> PLAYING
PLAYING --(score >= target)--> WON
PLAYING --(time == 0 且 score < target)--> LOST
WON/LOST --(重开输入)--> READY
```

| 状态 | 倒计时 | 抓钩输入 | HUD/面板 |
|---|---:|---:|---|
| `BOOT` | 否 | 否 | 加载状态，正常情况不停留 |
| `READY` | 否 | 否 | 显示操作与目标 |
| `PLAYING` | 是 | 是 | HUD 实时更新 |
| `WON` | 否 | 否 | 胜利面板 + 重开 |
| `LOST` | 否 | 否 | 失败面板 + 重开 |

结算顺序：若同一帧送达物件且倒计归零，先结算送达；分数达标则 `WON`，否则 `LOST`。

实现约束：倒计首次到 0 时设置 `timeout_pending`，在当前物理帧信号处理结束后再统一决定胜负；不允许因节点处理顺序导致同帧送达在不同运行中得到不同结果。

## 4. 信号拓扑

```text
Input -> Main -> HookController.try_launch()
HookController.catch_attached -> Catchable.attach_to_hook()
Catchable.collected -> RoundController.add_score()
RoundController.score_changed/time_changed -> GameHud
RoundController.round_finished -> HookController.disable + ResultOverlay
ResultOverlay.restart_requested -> RoundController.restart_round()
```

- 固定信号连接优先保存在 `.tscn`。
- 不使用事件总线或全局 Autoload；MVP 根场景直接持有 Round/Hook/HUD。

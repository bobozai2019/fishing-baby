# 场景与视觉契约

状态：`frozen`

## 1. 场景边界

| 场景 | 根节点 | 拥有内容 | 不得拥有 |
|---|---|---|---|
| `scenes/main.tscn` | `Node` | 组装关卡、HUD、RoundController，输入路由 | 具体鱼移动或抓钩物理 |
| `scenes/environment/ocean_environment.tscn` | `Node2D` | 环境、船与 `RopeOrigin` | 抓钩状态、抓取物、回合/UI |
| `scenes/entities/boat.tscn` | `Node2D` | 船身、角色头部与 `RopeOrigin` | 抓钩状态、回合/UI |
| `scenes/gameplay/demo_catchables.tscn` | `Node2D` | 12 类抓取物的固定实例与初始位置 | 背景、抓钩、回合/UI |
| `scenes/gameplay/fishing_level.tscn` | `Node2D` | 组装 OceanEnvironment、DemoCatchables 和 HookRig | 回合计分/UI |
| `scenes/gameplay/hook_rig.tscn` | `Node2D` | `Line2D`、Hook Sprite、Tip Area/Shape、抓钩状态 | 回合分数 |
| `scenes/entities/catchable.tscn` | `Area2D` | Sprite、CollisionShape、移动/挂载行为 | 关卡时间与目标分 |
| `scenes/ui/game_hud.tscn` | `Control` | 倒计时、分数/目标、操作提示 | 游戏运动 |
| `scenes/ui/round_result_overlay.tscn` | `Control` | 胜/负、最终分、重开按钮 | 直接重载文件或写存档 |

## 2. `ocean_environment.tscn` 必需节点

```text
OceanEnvironment
├── Environment
│   ├── SkyWaterSand
│   ├── Clouds
│   ├── Island
│   └── SeabedDecor
├── Boat (boat.tscn, boy_head)
│   ├── Body (Sprite2D)
│   ├── Head (Sprite2D)
│   └── RopeOrigin (Marker2D)
└── Boat2 (boat.tscn, girl_head)
    ├── Body (Sprite2D)
    ├── Head (Sprite2D)
    └── RopeOrigin (Marker2D)
```

`fishing_level.tscn` 另外必须提供 `Bounds`，并将 `RopeOrigin` 作为明确 `NodePath` 传给 HookRig，不依赖模糊的父级查找。

- `RopeOrigin` 由 `boat.tscn` 提供；环境中的实例可以覆盖局部位置，但必须保持与对应 HookRig 的世界坐标一致。
- 抓钩资源连绳参考点为原图局部 `(512, 64)`。
- 绳子必须用 `Line2D`，不生成绳索位图。
- 碰撞使用手工 `CircleShape2D`/`CapsuleShape2D`，不依 Alpha 自动生成。

## 3. 视觉层级

| 层级 | 建议 z-index | 内容 |
|---|---:|---|
| 远景 | -30 | 天空、云、灯塔岛 |
| 水体/沙床 | -20 | 9-slice 水体、沙床 |
| 海底装饰 | -10 | 左右装饰 |
| 抓取物 | 0 | 鱼、生物、杂物 |
| 船/水面波浪 | 10 | 船与波浪条 |
| 绳/抓钩 | 20 | 需始终可见 |
| 世界反馈 | 30 | 得分飘字、命中反馈 |
| HUD/弹层 | CanvasLayer | 不受世界缩放影响 |

## 4. 资源使用口径

- 场景优先使用 `resources/environment_sliced/` 的可拉伸天空、水体、沙床、云、灯塔岛与左右装饰。
- 船只统一实例化 `scenes/entities/boat.tscn`，不再直接使用旧的整船人物合成图。
- 船身使用 `resources/characters/boat_body.png`。
- 默认角色头部使用 `resources/characters/boy_head.png`，女孩实例将 `Head.texture` 覆盖为 `resources/characters/girl_head.png`。
- 抓钩使用 `resources/tools/claw-hook.png`。
- 所有 5 种鱼必须在 `AVAILABLE` 显示 swim 图，`HOOKED` 显示 caught 图并做轻微往复旋转。
- HUD 优先使用 `hud-panel.svg`、`icon-clock.svg`、`icon-coin.svg`、`icon-hook.svg`。
- `fish-preview.png`、`non-fish-preview.png`、`previews/`、`sources/` 不作为运行时贴图。

## 5. 美术和资源新增规则

- MVP 默认不新增位图。
- 如 Gate 2 发现阻塞级缺口，新资源必须是美漫卡通、粗轮廓、高饱和平涂风，使用 `resources/PROMPTS.md` 中的无灯光约束。
- 新资源放入 `resources/` 下职责明确的目录，并为新建目录补 `index.md`。
- 不为了 MVP 重组、重命名或批量格式化现有资源。

## 最终验收标准

1. 所有自动测试通过，无 parse/resource load error。
2. Windows 和 Web 均通过 E2E-01/02/03，失败流程至少在一个平台验证。
3. Web 控制台无致命错误，输入不导致页面滚动或焦点丢失。
4. 没有运行时存档/网络路径，没有 vNext UI 入口。
5. Gate 3 报告记录命令、结果、截图和已知限制；总体进度才可标记 100% [已完成]。

# 构建产物与体积契约

状态：frozen（Gate 1，2026-08-09）

## 构建入口

- 正式入口：根目录 `build.bat`。
- 正式 raw 输出：`build/web_playtest/`。
- 构建前只允许递归清理已解析且等于 `<project>/build/web_playtest` 的目录。
- 自定义模板缺失、版本不符、编译配置哈希不符时必须失败，不得静默回退官方模板。
- 回滚模式必须显式选择官方模板，并在日志中标记 `template_kind=stock`。

## 模板 provenance 字段

执行阶段生成 `tools/web_templates/godot-4.7.1-2d.provenance.json`：

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `godot_version` | string | 是 | 必须为 `4.7.1.stable` 等价官方版本标识 |
| `source_commit` | string | 是 | 40 位 commit |
| `source_dirty` | boolean | 是 | 必须为 `false` |
| `emscripten_version` | string | 是 | 实际命令输出 |
| `scons_version` | string | 是 | 实际命令输出 |
| `build_profile_sha256` | string | 是 | 64 位小写十六进制 |
| `scons_args` | array[string] | 是 | 排序或保持实际调用顺序 |
| `template_sha256` | string | 是 | release zip 哈希 |
| `created_at` | string | 是 | ISO-8601 |

## 体积 manifest 字段

正式构建生成 `size-manifest.json`，至少包含：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `build_id` | string | 是 | 可追溯构建标识 |
| `template_kind` | enum | 是 | `stock` / `custom_release` / `custom_e2e` |
| `files[].path` | string | 是 | 相对输出目录 |
| `files[].raw_bytes` | integer | 是 | 原始文件字节 |
| `files[].brotli_path` | string/null | 是 | `.br` 表示路径 |
| `files[].brotli_bytes` | integer/null | 是 | Brotli 字节 |
| `files[].sha256` | string | 是 | 原文件哈希 |
| `raw_total_bytes` | integer | 是 | raw 文件集合总和 |
| `upload_artifact_bytes` | integer/null | 是 | Gate 0 平台口径对应制品 |
| `brotli_transfer_bytes` | integer | 是 | 浏览器实际传输表示总和 |
| `budget_bytes` | integer | 是 | Gate 0 冻结值 |
| `budget_metric` | enum | 是 | `raw` / `upload` / `transfer` |
| `budget_passed` | boolean | 是 | 严格按冻结口径计算 |

## 预算

- Brotli 传输：必须 `< 25 MiB`，期望 `≤15 MiB`。
- `index.wasm` raw：目标 `≤17.0 MiB`。
- `index.pck` raw：不得高于 `7.5 MiB`，除非有经批准的资源变更。
- raw 总目录：目标 `<25 MiB`；是否为硬门禁由 Gate 0 冻结。

## 验收

1. manifest 总和必须与文件系统逐字节一致。
2. 模板 provenance 哈希必须与实际 export preset 使用的 zip 一致。
3. 连续两次构建若哈希不同，必须解释时间戳或非确定性来源。

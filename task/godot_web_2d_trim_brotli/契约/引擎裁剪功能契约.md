# 引擎裁剪功能契约

状态：frozen（Gate 1，2026-08-09）

## 必须保留

| 能力 | 消费方 | 验收 |
|---|---|---|
| GDScript 与全局 class cache | 全部运行脚本 | 主场景/PCK 启动无 parse error |
| 2D 渲染、CanvasItem、GL Compatibility | 所有场景与 Sprite/UI | 三视口截图 |
| 2D 物理、Area2D、CollisionShape2D | 抓钩、鱼、道具 | core/E2E 捕获与道具 |
| 基础 Control、Label、Button、Container | HUD/结算 | E2E UI 状态与点击 |
| 高级文本服务器或经验证的中文等价能力 | 中文 HUD/反馈 | 无方框、无缺字 |
| WebP 导入纹理解码（源图为 PNG、运行时 `.ctex` 为 WebP） | 全部美术 | 场景资源加载无缺失 |
| JavaScriptBridge 基础能力 | Web/E2E | 按 release/E2E 变体冻结 |
| Web 单线程模板 | 当前 export preset | 启动与并发头契约 |

## 首批允许禁用候选

| 候选 | 初始结论 | 前置验证 |
|---|---|---|
| 3D 渲染 | disable | 场景节点类型扫描无 3D |
| 3D 物理、Jolt | disable | 项目仅使用 2D 碰撞；移除无效 3D provider 配置另行决策 |
| Advanced GUI | disable candidate | 当前节点不使用禁用列表中的控件 |
| Navigation 2D/3D | disable | 无导航节点/API |
| XR/WebXR/OpenXR | disable | 无依赖 |
| 3D 导入模块、lightmapper、mesh modules | disable | 无 3D 资源 |
| 视频、互动音乐、未使用音频编解码 | disable candidate | 当前无音频/视频正式资源 |
| Multiplayer/WebRTC/WebSocket/ENet | disable candidate | 当前无联网功能 |
| Debug symbols/deprecated APIs | disable | release only |
| Web threads/GDExtension dlink | disable | export preset 已关闭 |

## 禁止直接禁用

1. `module_gdscript`。
2. 2D physics。
3. 当前中文文本能力；fallback text server 未通过中文验收前不得替换。
4. GL Compatibility 所需 OpenGL/WebGL 路径。
5. 仅因静态检测未发现就关闭动态加载相关能力；必须先核对脚本字符串加载与 autoload UID。

## 配置冻结方式

- T02 运行 Godot 引擎编译配置检测，生成初始 `.gdbuild`。
- T02 结合 `scons --help` 和项目节点/脚本扫描人工复核。
- 每轮 T03 只改变一个逻辑分组，记录参数差异、WASM 差值和运行结果。
- release/E2E 的唯一允许差异必须列在 Gate 1 报告。

# 决策记录

## ADR-001：使用隔离的干净 Godot 4.7.1 stable 源码

- 日期：2026-08-09
- 状态：accepted
- 背景：本机 `D:/godot/godot_master` 有用户改动且并非可证明的 4.7.1 stable 干净树。
- 决策：执行时在 `tools/` 下准备精确 tag/commit 的隔离源码，不修改既有引擎树。
- 影响：T01、T03。

## ADR-002：体积采用三种独立口径

- 日期：2026-08-09
- 状态：accepted
- 背景：raw 文件、上传制品和 HTTP Brotli 传输量不能互相代替。
- 决策：每次正式测量同时报告 `raw_total_bytes`、`upload_artifact_bytes`、`brotli_transfer_bytes`。
- 影响：T00、T04、T06。

## ADR-003：Release 与 E2E 模板允许受控差异

- 日期：2026-08-09
- 状态：accepted
- 背景：`scripts/tools/e2e_bridge.gd` 使用 `JavaScriptBridge.eval()`，最大裁剪 release 可能不需要该能力。
- 决策：优先保持同一裁剪基线；若关闭 JS eval 能显著降包且不影响正式功能，则单独保留 E2E 模板，并用黑盒 smoke 验证最终 release。
- 影响：T02-T05。

## ADR-004：正式与 E2E 共用裁剪模板，隔离编辑器插件

- 日期：2026-08-09
- 状态：accepted
- 背景：GodotIQ 编辑器调试 autoload 直接引用 3D、NavigationServer3D 和高级 GUI 类型，不能进入纯 2D 运行时；游戏 E2E bridge 则仍需要 JavaScriptBridge。
- 决策：正式与 E2E 使用同一 Web 模板；导出时复制最小运行时项目到固定 staging，移除 editor plugin/autoload。正式 preset 不启用 E2E bridge，E2E preset 显式启用。
- 影响：T03-T05。

## ADR-005：保留 fallback text 与 WebP，禁用 advanced text 与 Basis

- 日期：2026-08-09
- 状态：accepted
- 背景：项目中文为简体静态字符且不需要复杂排版；实际 `.ctex` 载荷为 WebP，不是 Basis。
- 决策：保留 fallback text 和 `module_webp`；禁用 advanced text 与 Basis。用实际字体子集、中文 UI 和三视口截图验证等价性。
- 影响：T02-T05。

## ADR-006：固定场景 UID/node ID 作为可重复构建输入

- 日期：2026-08-09
- 状态：accepted
- 背景：修改后的 `catchable.tscn` 缺少稳定节点 ID，Godot 每次新编译会写入随机 `node_ids`，导致 PCK SHA 与 Brotli 字节波动。
- 决策：为该场景、外部资源和节点补齐稳定 UID/unique_id；连续两次正式完整构建必须 manifest 完全一致。
- 影响：T05-T06。

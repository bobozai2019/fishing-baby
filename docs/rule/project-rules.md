# 项目规则

## 代码与场景构建

1. 场景优先固化，脚本动态创建最小化。
2. 能够预先确定的节点、布局、视觉层级、资源绑定及固定信号连接，应在 Godot 编辑器中完成并保存到场景（`.tscn`）或资源（`.tres`）中。
3. 只有确实需要在运行时生成、数量不固定、临时存在或由数据驱动的对象，才使用脚本动态创建。不得在 `_ready()` 中重建静态场景或 UI 层级。

## 美术风格

1. 角色、场景、UI、特效及宣传素材统一采用美漫卡通风。
2. 优先使用鲜明轮廓、粗线条、夸张比例与表情、高饱和对比色，以及图形化或赛璐璐式明暗。
3. 除非有明确记录的例外，不使用写实、低饱和写实渲染或其他不统一的美术风格。
